# numerical_integration_damped_harmonic_oscillator
Numerical simulation of damped and driven harmonic oscillators using Euler, improved Euler, Verlet and Euler–Cromer integration methods, with comparisons of numerical accuracy, stability and resonance behaviour.

Project 2 of the module PHYS20762 Computational Physics (Year 2, Semester 4, 2025). This project has been committed to GitHub much later.
